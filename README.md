# NEMA Receptacles SVG Collection

This repository contains vector SVG front-face illustrations for the standard and locking NEMA receptacles requested for web use.

## Directories

- `standard/` — 125V/240V/480V straight-blade receptacles
- `locking/` — locking receptacles and twist-lock variants

## Included receptacles

### Standard
- NEMA 5-15R
- NEMA 5-20R
- NEMA 6-15R
- NEMA 6-20R
- NEMA 8-20R
- NEMA 8-30R
- NEMA 8-50R
- NEMA 10-30R
- NEMA 14-20R
- NEMA 14-30R
- NEMA 14-50R

### Locking
- NEMA L6-20R
- NEMA L6-30R
- NEMA L6-50R
- NEMA L14-20R
- NEMA L14-30R
- NEMA L14-50R
- NEMA L15-20R
- NEMA L21-20R
- NEMA L21-30R
- NEMA L23-30R
- NEMA L23-50R

All SVGs are scalable, use a neutral light background, and include the NEMA designation and voltage/amperage annotation.
